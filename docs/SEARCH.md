# SEARCH

الكود: `search/engine.py` (المحرك)، `catalog/indexing.py` (الفهرسة)، `search/analytics.py` (السجل).

## مراحل الاستعلام

| المرحلة | التنفيذ |
|---|---|
| معرّفات | ISBN-10/13 (بشرطات أو بدونها) أو DOI → مطابقة مباشرة |
| التطبيع | `normalize_key`: همزات، ى/ي، ة/ه، تشكيل، تطويل، "ال" وحروف الجر الملتصقة، أرقام هندية، lowercase |
| المرادفات | `search.Synonym` (تُعدّل من الإدارة): كل مجموعة تولّد صيغًا بديلة، حتى 8 صيغ |
| المطابقة (PostgreSQL) | `search_vector @@ tsquery` بإعداد `simple`؛ كل كلمات الصيغة مطلوبة، الصيغ بينها OR، وآخر كلمة prefix (`:*`) |
| تحمّل الأخطاء | إن لم توجد نتائج: `strict_word_similarity` (pg_trgm) على العنوان ≥ `typo_threshold`، وتُعلَّم النتائج "تقريبية" |
| المطابقة (SQLite) | `icontains` على `search_document` (للتطوير فقط) |

## ما يُفهرس (`search_document`)

العنوان، العنوان الفرعي، العنوان الأصلي، المساهمون (الاسم والاسم الأصلي)، الموضوعات بالعربية والإنجليزية مع آبائها،
الكلمات المفتاحية، الناشر، عنوان الطبعة، ISBN، وأول 1500 حرف من الوصف — كلها بعد التطبيع.
`search_vector` = العنوان (وزن A) + المستند (وزن B). فهارس GIN على `search_vector` و`normalized_title gin_trgm_ops`.

التحديث تلقائي عبر الإشارات عند حفظ العمل/المساهمة/الطبعة/الموضوعات. الاستيراد الجماعي يعلّق الإشارات ويفهرس مرة لكل سجل.
`python manage.py rebuild_search_index [--missing]` (والـ entrypoint يشغّل `--missing` عند كل تشغيل).

## الترتيب (`search.SearchSettings` — الإدارة ← البحث ← إعدادات ترتيب البحث)

```
rank = ts_rank_cd(search_vector) × text_weight
     + similarity(normalized_title, query) × title_weight
     + free_access_bonus  (رابط وصول مجاني موثّق)
     + verified_bonus     (بيانات العمل مُتحقق منها)
     + arabic_bonus       (لغة أصلية أو طبعة عربية)
     + recency × recency_weight   (سنة آخر طبعة، 1900→0 ، 2030→1)
```

القيم الافتراضية: 2 / 3 / 0.4 / 0.2 / 0.5 / 0.1، وحد تحمّل الأخطاء 0.45.
الترتيبات الأخرى: الأحدث نشرًا، الأحدث إضافة، العنوان.

## الأداء (6 آلاف عمل محليًا)

بحث عادي 20–60ms، بحث تقريبي 80–100ms، الاقتراحات أسرع (8 نتائج).

## التحليلات

`search.SearchLog`: النص، النص المطبّع، عدد النتائج، التصفية، الوقت. **لا مستخدم ولا IP ولا جلسة.**
لا يُسجَّل: الزواحف (User-Agent)، الاقتراحات أثناء الكتابة، الصفحات التالية من نفس البحث.
صفحة الإدارة **سجل البحث ← تحليلات البحث**: الأكثر بحثًا، وما يُبحث عنه ولا نملكه (بلا نتائج) لمعرفة ما ينقص المكتبة.
الرئيسية تعرض "الأكثر بحثًا" (تكرر مرتين على الأقل خلال 30 يومًا وله نتائج).
