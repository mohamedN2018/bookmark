# ARABIC NLP

`core/arabic.py`

| القاعدة | مثال |
|---|---|
| حذف التشكيل والتطويل | الذَّكاءُ → الذكاء ، الذكـــاء → الذكاء |
| توحيد الألف والهمزات | أ إ آ ٱ → ا ، ؤ → و ، ئ → ي |
| الياء والتاء المربوطة | ى → ي ، ة → ه |
| الأرقام | ٢٠٢٤ / ۲۰۲۴ → 2024 |
| اللاتيني | lowercase + إزالة العلامات (é → e) |
| الترقيم | يصبح مسافة، ثم ضغط المسافات |
| أداة التعريف (`normalize_key`) | ال، وال، بال، كال، فال، لل تُحذف إن بقي بعدها حرفان على الأقل |

```python
normalize_key("الذكاء الإصطناعي") == normalize_key("ذكاء اصطناعي") == "ذكاء اصطناعي"
normalize_key("Python البرمجة") == "python برمجه"
```

الاستخدام: `Work.normalized_title`، `Person.normalized_name`، `Publisher.normalized_name`، `Subject.normalized_name`
تُحسب تلقائيًا عند الحفظ، وتُستخدم في البحث (المرحلة 4) وكشف التكرار (المرحلة 7).
