# SOURCES

## السجل (`sources.Source`)

كل مصدر: النوع، المالك، النطاق، API، البحث، البيانات الوصفية، سياسة الوصول القانونية، رابط الشروط،
رخصة البيانات الوصفية، **السماح بإعادة الاستضافة** (افتراضيًا لا)، حد الطلبات، الأولوية، الموثوقية، الحالة، آخر مزامنة.

## المزوّدات المنفذة

| المصدر | الطريقة | الملفات | الحقوق |
|---|---|---|---|
| **OAPEN Library** | OAI-PMH `xoai` (REST يتطلب تسجيلًا مسبقًا ويرد 403) | PDF يُنزّل ويُستضاف مع تحقق MD5، وغلاف | رخصة CC صريحة لكل ملف (`rights`/`rightsuri`) |
| **Project Gutenberg** | ملف الفهرس الرسمي `pg_catalog.csv` | ربط بالقراءة (HTML) والتحميل (EPUB) من Gutenberg | ملكية عامة في الولايات المتحدة |

## إضافة مزوّد جديد

1. صنف يرث `SourceProvider` في `sources/providers/` ويعرّف: `key`، `allowed_hosts`، `can_host_files`،
   `iter_records()`، `normalize()` (و`validate()` اختياريًا).
2. سجله في `sources/providers/__init__.py`.
3. migration تضيف سجل `Source` بنفس `slug = key` مع سياسة الوصول الحقيقية للمصدر.
4. اختبارات على سجل حقيقي محفوظ في `sources/tests/fixtures/`.

لا تغيير مطلوب في الفهرس أو الواجهات أو خط الاستيراد.

## مرشحون لاحقون

DOAB (OAI-PMH يعمل)، arXiv (API يعمل؛ ربط فقط لأن رخصة arXiv الافتراضية لا تسمح بإعادة الاستضافة)،
OpenAlex وCrossref (بيانات وصفية ومعرّفات)، Internet Archive (مجموعات مكتبات موثوقة فقط).
